# Qexdy3

Новая вкладка Chrome с живыми обоями, удобными ссылками и дополнительной чёрной темой AMOLED.

## Возможности

- Пять встроенных видеообоев и импорт собственных видео или изображений.
- Выбор, перемешивание и удаление обоев, в том числе встроенных.
- Регулировка громкости от 0 до 100 %, повтор и пауза при скрытии вкладки.
- Сохранённые ссылки с автоматическими иконками и возможностью загрузить собственную иконку для каждой ссылки.
- Часы, дата, необязательная погода и настройки оформления.
- Собственная иконка вкладки и кнопки расширения.
- Отдельная тема **AMOLED Pure Black** для интерфейса Chrome.

Настройки и список ссылок сохраняются в `chrome.storage.local`, загруженные файлы обоев — в IndexedDB. Расширение использует Manifest V3 и не требует установки библиотек или сборки.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `1.0.0_0`.
4. При необходимости подтвердите использование новой вкладки Qexdy3 в Chrome.
5. Чтобы установить чёрную тему, снова нажмите **Загрузить распакованное расширение** и выберите папку `AMOLED-Black`.

Тема и новая вкладка устанавливаются отдельно: тема меняет оформление интерфейса браузера, а Qexdy3 — содержимое новой вкладки. Чтобы вернуться к стандартной теме, откройте настройки Chrome → **Внешний вид → Тема → Сбросить**.

Если Chrome сообщает о конфликте идентификаторов, отключите или удалите прежнюю установленную копию расширения перед загрузкой распакованной версии. Удаление расширения может удалить его локальные данные.

## Использование

- Кнопка обоев открывает библиотеку и импорт файлов; в библиотеке можно выбрать или удалить обои.
- Ползунок внизу управляет громкостью. Настройка сохраняется после перезапуска браузера.
- Для редактирования ссылки нажмите `•••`. Кнопка **Choose icon** позволяет выбрать изображение, а **Use site icon** возвращает автоматическую иконку.
- Общую иконку вкладки и кнопки расширения можно изменить в **Settings → Appearance**. Значок в списке расширений Chrome задаётся манифестом и не меняется этой настройкой.

## Конфиденциальность и сеть

- Для автоматических значков ссылок домен сайта передаётся сервису Google Favicons. Путь и параметры URL не отправляются; при заданной пользователем иконке запрос не нужен.
- Погода необязательна и запрашивает разрешение на доступ к `wttr.in`. При включении передаётся город, приблизительно определённый по часовому поясу; сервис также получает IP-адрес запроса. Геолокация не используется.
- Встроенные ссылки на внешние сайты открываются только при выборе пользователем.

## Структура

```text
1.0.0_0/       Распакованное расширение Qexdy3
AMOLED-Black/  Отдельная тема Chrome
```

Qexdy3 основан на расширении Anime Live Wallpaper; в проекте сохранены ссылки на его сайт и ресурсы. Права на исходные материалы и видео принадлежат соответствующим правообладателям; наличие файлов в репозитории само по себе не означает предоставления отдельной лицензии.
